## # Douglas Prudenciano

**`Analista de Dados`**

Me chamo Douglas Prudenciano, tenho 28 anos e sou natural de Campinas, SP. Atualmente, estou cursando Análise e Desenvolvimento de Sistemas na Universidade Paulista (UNIP).
